Un incidente dura un rato.
El acceso también debería.

Inés necesita consultar un reporte. Mateo revisa la solicitud. El permiso termina cuando se resuelve el incidente o vence su ventana.

  1. Solicitud

    Un destino. Un motivo. Un plazo.

    El catálogo limita qué puede pedir cada persona o agente y por cuánto tiempo.

    analytics / readonly / 20m
  2. Aprobación

    Otra persona toma la decisión.

    El solicitante no aprueba su propio acceso. Lease registra quién decidió y cuándo.

    Inés solicita → Mateo aprueba
  3. Salida

    Revocar y comprobar.

    El worker retira el permiso y consulta el destino. Si falla, conserva el intento pendiente para reintentar.

    active → revoking → revoked

El límite del plazo
